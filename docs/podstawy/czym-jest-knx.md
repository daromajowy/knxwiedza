# Czym jest KNX

KNX to otwarty, międzynarodowy standard automatyki domów i budynków, który łączy oświetlenie, ogrzewanie, rolety, bezpieczeństwo i zarządzanie energią w jeden system ([knx.org](https://www.knx.org/explore-knx/what-is-knx)). Działa jak wspólny język dla urządzeń różnych producentów, więc nie trzeba osobnych aplikacji ani zamkniętych systemów jednej marki.

| Wskaźnik | Wartość podana na knx.org |
| --- | --- |
| Certyfikowane urządzenia | ponad 8 000 |
| Producenci | ponad 500 |
| Certyfikowani instalatorzy | ok. 140 000 |
| Kraje z projektami | 180–190 (strona podaje obie liczby) |
| Historia standardu | ponad 30 lat (miejscami 35+) |

KNX nie należy do jednej firmy. Standard rozwija i certyfikuje **KNX Association** (Bruksela), zrzeszająca producentów, centra szkoleniowe, partnerów naukowych, laboratoria testowe i grupy krajowe ([community](https://www.knx.org/community)).

!!! info "Uzupełnienie spoza knx.org (wiedza ogólna)"

    KNX powstał w 1999 r. z połączenia trzech systemów: EIB, BatiBUS i EHS. Jest normą europejską EN 50090, międzynarodową ISO/IEC 14543-3 oraz chińską GB/T 20965. Strona knx.org mówi tylko, że KNX jest „zbudowany na globalnych standardach”, bez numerów norm.
