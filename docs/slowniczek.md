# Zalety, ograniczenia i słowniczek

**Zalety (wg knx.org):** brak uzależnienia od jednej marki, certyfikowana zgodność urządzeń, kompatybilność wsteczna i możliwość rozbudowy, skalowalność od domu po lotnisko, praca lokalna bez chmury, oszczędność energii, wbudowane zabezpieczenia.

**Ograniczenia (wniosek własny, nie z knx.org):** wyższy koszt urządzeń niż w systemach Wi-Fi, potrzeba okablowania magistrali na etapie budowy, płatna licencja ETS i konieczność zatrudnienia przeszkolonego instalatora. Knx.org nie podaje kosztów ani zwrotu z inwestycji.

## Słowniczek

| Pojęcie | Znaczenie |
| --- | --- |
| Aktor | Urządzenie wykonawcze, np. moduł przełączający, ściemniacz, sterownik rolet |
| Czujnik | Urządzenie wysyłające polecenia, np. przycisk, czujnik ruchu, termostat |
| Adres fizyczny | Unikalny adres urządzenia w topologii, np. 1.1.5 |
| Adres grupowy | Adres funkcji, który wiąże czujniki z aktorami, np. 1/0/1 |
| DPT | Typ punktu danych: format wartości w telegramie |
| Sprzęgło | Urządzenie łączące linie, obszary lub media i filtrujące telegramy |
| ETS | Oficjalne oprogramowanie do projektowania i uruchamiania KNX |
| KNX Secure | Szyfrowanie i uwierzytelnianie komunikacji KNX |
| KNX IoT | Rozszerzenie KNX na sieci IPv6 (Wi-Fi, Ethernet, Thread) z otwartym API |
