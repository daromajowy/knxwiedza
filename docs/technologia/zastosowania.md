# Zastosowania

Jeden system KNX obsługuje osiem kategorii urządzeń, z których knx.org buduje swój katalog ([urządzenia](https://www.knx.org/devices)):

| Kategoria | Przykłady funkcji |
| --- | --- |
| Oświetlenie | przełączanie, ściemnianie, DALI (np. Secure DALI), sterowanie wg pory dnia |
| HVAC | ogrzewanie zależne od pogody, klimatyzacja, wentylacja, jakość powietrza |
| Rolety i zaciemnianie | żaluzje, markizy, ochrona przed słońcem |
| Zarządzanie energią | integracja fotowoltaiki, pomiar i ograniczanie zużycia |
| Bezpieczeństwo i kontrola dostępu | symulacja obecności, alarmy, powiadomienia |
| Sceny i automatyka | sceny, logika, scenariusze dnia |
| Zdalne sterowanie | aplikacje, panele, wizualizacje |
| Audio/wideo | sterowanie systemami AV |

Typowe obiekty z galerii projektów to mieszkania, domy jednorodzinne, wille, hotele, lotniska, biurowce, szpitale, szkoły, obiekty rekreacyjne i budynki publiczne ([projekty](https://www.knx.org/projects)). Ta sama wiedza skaluje się od modernizacji jednego pokoju po kampusy i lotniska ([dla instalatorów](https://www.knx.org/explore-knx/knx-for-installers)).

**Jak zacząć jako inwestor:** bezpłatny KNX Smart Home Planner (planning.knx.org) tworzy raport potrzeb, który przekazuje się certyfikowanemu instalatorowi z katalogu [Find an installer](https://www.knx.org/find-an-installer) ([dla właścicieli](https://www.knx.org/explore-knx/knx-home-building-owners)).
